# Guides Overview

Task-oriented walkthroughs for **end users and operators**. Pick the goal you have in mind and follow the steps.

New to CDT? Start with the [Quickstart](../getting-started/quickstart.mdx), which threads the most important guides into a single 30-minute path.

| You want to… | Read |
|--------------|------|
| Browse buildings, datasets, and the city on a map | [Map Viewer](./map-viewer.md) |
| Open and inspect an IFC building model | [BIM Viewer](./bim-viewer.md) |
| Visualize a LiDAR or photogrammetry scan | [Point Clouds](./point-clouds.md) |
| Add and organize buildings and sites | [Buildings & Sites](./buildings-and-sites.md) |
| Upload and manage files | [File Management](./file-management.md) |
| Connect IoT and sensor data | [Sensors & IoT Data](./sensors-and-iot.md) |
| Discover and overlay open data | [Datasets & Open Data](./datasets-and-open-data.md) |
| Invite teammates, comment, share views | [Collaboration](./collaboration.md) |

Keystrokes are written `Ctrl + S` on Windows and Linux, `Cmd + S` on macOS. Placeholders in code blocks use `<angle brackets>`.

If a step does not work as described, check [Troubleshooting](../getting-started/troubleshooting.mdx), then [GitHub issues](https://github.com/CollabDigitalTwins/core/issues).
