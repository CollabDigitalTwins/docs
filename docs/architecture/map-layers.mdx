# Map Layers

The map viewer composes a fixed set of named layers declared in `@collabdt/core/components/viewers/map/src/MapLayers/`. Each layer is a self-contained React component responsible for fetching its own data, adding MapLibre sources and layers, and registering a click handler with `MapClickManager`.

## Layer Composition

`MapLayers` renders all layers in a fixed stacking order:

```tsx
// @collabdt/core/components/viewers/map/src/MapLayers/index.tsx
export const MapLayers = () => (
  <>
    <CountryLayer />
    <OpenDataLayers />
    <BuildingLayer maptilerKey={maptilerKey} />
    <CommentLayer />
    <SensorLayers />
    <FileLayers />
    <BimLayer />
  </>
)
```

Render order affects visual stacking but click priority is controlled separately by `MapClickManager` — see [Map Click Manager](./map-click-manager.mdx).

## Layers

### CountryLayer

Renders country, region and subdivision boundary outlines, and tracks which administrative subdivision the camera is looking at. Does not register a click handler.

Country and region borders come from MapTiler's vector tiles on the deployment's `MAPTILER_KEY`, falling back to MapTiler's localhost-only placeholder key. Subdivision polygons for the organization's own country come from ArcGIS World Administrative Divisions and need no key, so subdivision borders render on every deployment and on every base style.

`currentLocation.countrySubdivision` follows the **camera**, not the pointer: after each `moveend` the layer resolves the polygon under the camera target and commits its ISO 3166-2 code, also writing it to the `countrySubdivision` URL parameter. Hovering only thickens the border of the subdivision under the cursor, and only above zoom 10 — there is no fill, so imagery is never tinted. Subdivision borders are hidden above zoom 15, where building-scale detail takes over; the invisible hit-test polygons remain at every zoom, so camera tracking keeps working past that point. When the camera target falls outside the loaded polygons — over water, or in another country — the last resolved value is kept. An organization with a fixed `countrySubdivision` or `municipality` skips all of this: those values are pushed into `currentLocation` once and the layer renders nothing.

**Sources:** `openmaptiles-boundaries` (MapTiler vector tiles), `admin-subdivisions-source` (ArcGIS GeoJSON).

---

### BuildingLayer (`BuildingLayer`)

Renders CDT buildings as 3D extrusions. Highlights a building when selected and hides buildings whose IFC model is loaded in the BIM viewer (to avoid visual overlap).

The layer brings its own building tile source (`cdt-buildings`, from MapTiler's buildings tileset on the deployment's `MAPTILER_KEY`), so buildings are interactive on **every** base style rather than only the MapTiler ones. Without a key it reuses a buildings-capable vector source already present in the style (`openmaptiles`, `maptiler_planet`, `carto`) and otherwise falls back to MapTiler's localhost-only placeholder key.

**Data:** `useBuildings()` — all buildings for the active organization.  
**Layer ID:** `maptiler-3d-buildings`  
**Prop:** `maptilerKey` — passed down from `MapViewer` through `MapLayers`.  
**Click priority:** `BuildingLayersClickPriority = 100`  
**On click:** Opens a `MapFeaturePopoverMenu` with building details.

---

### CommentLayer (`CommentLayer`)

Renders user comments as avatar markers on the map. Clustered when zoomed out.

**Data:** `useComments()` — all comments for the active organization.  
**Click priority:** `CommentLayersClickPriority = 200`  
**On click:** Opens the comment detail popup.

---

### SensorLayers (`SensorLayers`)

Renders IoT sensors as icon markers. Icons are resolved from `SensorType.icon` (Lucide icon name). Clustered when zoomed out.

**Data:** `useSensors()`, `useSensorTypes()`.  
**Click priority:** No explicit priority registered — sensors use marker-level click events rather than MapLibre layer events.

---

### FileLayers (`FileLayers`)

Renders files that have been pinned to map coordinates (images, IFC footprints, etc.) as markers. Also handles 3D model overlays via a custom Three.js `CustomModelLayer`.

**Data:** `useFiles()`.  
**Click priority:** `FileLayerClickPriority = 400`

---

### OpenDataLayers (`OpenDataLayers`)

Renders datasets fetched from external open data portals (ArcGIS, CKAN, Opendatasoft) as vector or GeoJSON sources.

**Data:** Active datasets from `DatasetsProvider`.  
**Click priority:** `OpenDataLayerClickPriority = 350`  
**On click:** Shows dataset feature properties.

---

### BimLayer (`BimLayer`)

Renders the georeferenced footprint of a loaded IFC model on the map. Hides the corresponding MapTiler building polygon to avoid overlap.

**Data:** BIM model position from `BimProvider`.  
**Click priority:** `BimModelLayerPriority = 600`

---

### SiteLayer (utility, not in `MapLayers`)

`@collabdt/core/components/viewers/map/src/MapLayers/src/SiteLayer/index.ts` exports `createSitesDataset()`, a helper that converts `Site[]` to a GeoJSON `FeatureCollection` for use as an OpenDataLayer dataset. It is not a standalone layer component.

## Adding a New Layer

1. Create a component in `@collabdt/core/components/viewers/map/src/MapLayers/src/<YourLayer>/`.
2. Register a click handler using `MapClickManager.register()` with an appropriate priority from `MapLayerClickPriority`. Add a new enum value if none fits — see [Map Click Manager](./map-click-manager.mdx).
3. Add your component to `MapLayers/index.tsx`.
4. Call `MapClickManager.unregister()` in a `useEffect` cleanup to avoid leaking handlers on unmount.
